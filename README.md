## 🚀 How to Run the Website

### Option 1: Visual Studio Code with Live Server (Recommended)
1. Open Visual Studio Code.
2. Click **File > Open Folder...** and select `C:\xampp\htdocs\Julie2`.
3. If not already installed, install the **Live Server** extension by Ritwick Dey from the VS Code Extensions tab (`Ctrl+Shift+X`).
4. Right-click `index.html` and click **"Open with Live Server"**.
5. Your browser will immediately open `http://127.0.0.1:5500/index.html`!

### Option 2: Via Local XAMPP Apache Server
1. Open the **XAMPP Control Panel**.
2. Click **Start** beside **Apache**.
3. In any browser, navigate to:
   ```text
   http://localhost/Julie2/
   ```

### Option 3: Direct File Opening
Double-click `index.html` directly in your file explorer to launch it in your default web browser.

## 📸 How to Replace Your Photos and Music

### 1. Replacing Your 5 Memory Photos
Simply place your photos inside the `images/` folder with these exact names:
- `images/photo1.jpg` — Julie's solo photo
- `images/photo2.jpg` — Picture of the two of you together
- `images/photo3.jpg` — Today's food date
- `images/photo4.jpg` — Photobooth picture strip or photo
- `images/photo5.jpg` — Favorite moment from today

> **Tip:** If any image is temporarily missing, the webpage automatically displays a luxury golden placeholder card without breaking the layout.

### 2. Replacing the Phoenix Artwork
- Replace `images/phoenix.png` with any high-resolution image of your choice.

### 3. Replacing the Romantic Music
- Replace `music.mp3` in the root folder with any `.mp3` love song of your choice. Keep the file name `music.mp3`.
